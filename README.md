# LentisData public match data

Tämä `data`-haara sisältää julkiset ottelutilastot. Sovelluksen lähdekoodi on `main`-haarassa.

Synkronointipalvelu kirjoittaa tänne `matches/<match-id>/metadata.json`, `set-1.json` jne. ja `summary.json`.

Älä tallenna henkilötietoja, laiteavaimia tai tunnuksia tähän haaraan.
